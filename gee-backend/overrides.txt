# Resolver overrides for `uv pip compile --overrides overrides.txt`.
#
# fastapi-users-db-sqlalchemy 7.0.0 declares sqlalchemy[asyncio]<2.1.0.
# That pin blocks SQLAlchemy 2.1 even though our User model does NOT use
# MappedAsDataclass (the only SA 2.1 break tracked upstream —
# fastapi-users#1441). fastapi-users is in maintenance mode and will not
# lift the cap soon; Wave C5 overrides it so we can run SA 2.1 + psycopg3.
#
# Keep the [asyncio] extra on the override pin: a bare `sqlalchemy==X`
# replaces the direct `sqlalchemy[asyncio]` requirement and drops
# greenlet from the lock. CI/Docker install with --no-deps, so missing
# greenlet becomes ImportError on sqlalchemy.ext.asyncio.
#
# Supported combination (BE-12), pinned exactly and tested:
#   sqlalchemy==2.1.6
#   fastapi-users==15.0.5
#   fastapi-users-db-sqlalchemy==7.0.0
# Upstream still declares sqlalchemy<2.1. The only 2.1 break we tracked
# (MappedAsDataclass, fastapi-users#1441) is not used by app.auth.models.User.
# Do not bump one of the three without updating the other two and
# tests/new/test_sqlalchemy_supported_combination.py.
# Drop the override when fastapi-users-db-sqlalchemy allows sqlalchemy>=2.1.
sqlalchemy[asyncio]==2.1.6
